# 📦 Amazon 店舗 売上アップ分析

Amazonのお店の「成績表」を読んで、**どの商品を・どう直せば売上が上がるか**を自動で判定するしくみです。

---

## 🧩 しくみ（小学生向け）

売上は、かけ算でできています。

```
売上 ＝ 見に来た人（セッション） × 買う率（CVR） × 1個のねだん
```

どれか1つが弱いと、売上は伸びません。このプログラムは商品ごとに
「どこが弱いか」を見つけて、5つのグループに分けます。

| グループ | どういう状態？ | やること |
|---|---|---|
| 🔴 カートを取られている | お客さんは来ているのに、他のお店から買われている | 値段・在庫・発送日数を見直す |
| 🔴 見られているのに買われない | お店の前は人がいっぱい、でも買わずに帰る | 画像・タイトル・レビュー・値段を直す |
| 🟡 買われやすいのに人が来ない | 来た人はよく買うのに、来る人が少ない | 広告・キーワードで人を呼ぶ |
| 🟢 勝ち商品 | 人も来て、よく売れている | 在庫を切らさない・もっと伸ばす |
| ⚪ ほとんど動いていない | 人も来ないし売れない | 見直す、ダメなら売り切って止める |

🔴 から先にやると、いちばん早く売上が上がります。

---

## ▶️ 使い方（3ステップ）

### 1. 成績表CSVをダウンロード
1. セラーセントラルにログイン
2. 上のメニュー「レポート」→「ビジネスレポート」
3. 左の「商品別」→「**詳細ページ 売上・トラフィック（子商品別）**」
4. 期間を「過去7日間」などにして、右上の「ダウンロード(.csv)」

### 2. ファイルを置く
`amazon-shop/data/` に、日付の名前で置きます。

```
amazon-shop/data/2026-10-10.csv
```

毎週同じ曜日に置くと、**前回と比べて増えた・減った**も出ます。

### 3. 分析する
```bash
python3 amazon-shop/analyze.py
```

できあがるもの（`amazon-shop/output/`）：
- `report.html` … スマホで見られる診断レポート
- `todo.md` … 今週やることのチェックリスト
- `summary.json` … 数字のまとめ（あとで別の道具で使う用）

> CSVが置かれていないときは `sample/` のお試しデータで動きます。

---

## 🔒 大事：売上データを守るために

**このリポジトリは「公開」**（誰でも見られる）です。
そのため、
- `data/*.csv` と `output/` は **GitHubに上がらない設定**（`.gitignore`）にしてあります。
- 自動ワークフロー（`.github/workflows/amazon-shop-report.yml`）は
  **非公開リポジトリのときだけ**動くようにしてあります。

### 毎週の自動化をしたいとき
1. GitHubで**非公開（Private）の新しいリポジトリ**を作る
2. `amazon-shop/` フォルダと `.github/workflows/amazon-shop-report.yml` をコピー
3. `.gitignore` から `amazon-shop/data/*.csv` の行を消す（非公開なら置いてOK）
4. スマホのGitHubアプリから `data/` にCSVをアップロード → 自動でレポートが更新

---

## ⚙️ 判定のきびしさを変えたいとき

`analyze.py` の上のほうの数字を変えます。

| 名前 | 今の値 | 意味 |
|---|---|---|
| `BUYBOX_OK` | 90 | カート獲得率がこれ未満なら🔴 |
| `CVR_LOW_RATIO` | 0.6 | 買う率がお店平均の0.6倍未満なら「買われない」 |
| `CVR_HIGH_RATIO` | 1.3 | 買う率がお店平均の1.3倍以上なら「買われやすい」 |
| `TRAFFIC_TOP` | 0.7 | セッション数が上位30%なら「人がよく来ている」 |
