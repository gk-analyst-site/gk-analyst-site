# 📺 YouTube 毎朝の成長チェック

YouTubeチャンネルの数字を**毎朝じどうで集めて分析し、「今日なにをするか」を決める**しくみです。
あなたは朝、スマホで `output/today.html` を開いて「今日やること」を読むだけ。

---

## 🧩 小学生でもわかる・しくみの説明

```
① YouTube ──数字──► ② 分析プログラム ──今日の方向性──► ③ あなた
  (公式の窓口)          (毎朝6:30に自動で動く)              (読んで動画をつくる)
                              │
                              └─► ④ 日記(history/) に毎日ためる → 次の日の判断に使う
```

- **① YouTube の公式窓口（API）**：再生回数・高評価・投稿日などを正式に教えてくれる。
- **② 分析プログラム（`analyze.py`）**：次のことを調べます。
  - 昨日から**登録者・再生がどれだけ増えたか**、今どの動画が伸びているか
  - **ショート と 長い動画**、どっちがよく見られているか
  - 何**曜日**・何**時**に出した動画が伸びやすいか
  - **タイトルの型**（数字入り・【】・？ など）で差があるか
  - 伸びた動画に多い**タグ**、**投稿ペース**
  - （鍵2があれば）**最後まで見られた動画・登録者を増やした動画・どこから見に来たか**
- **③ 今日の方向性**：数字をもとに「今日やること3つ・次の動画案3本・今週ためす実験」を決めます。
- **④ 日記**：毎日の方針を `history/direction-log.md` にためます。
  次の日は「昨日の方針は数字にどう出たか？」を先にふり返ってから決めます。
  だから**方向性が毎日ブレずに、少しずつ良くなっていきます**。

> 「チャンネルの“ふつう”の何倍か」で比べています。
> “ふつう”＝公開から7日以上たった動画の再生回数の真ん中の値です。

## 🔑 準備：鍵を用意する（全部無料）

鍵が1つも無くても**デモモード**で動きます（サンプルの数字）。本物を分析するには鍵1が必要です。

| 鍵 | 必要？ | 分かること |
|---|---|---|
| 鍵1 `YT_API_KEY` | **必須** | 再生・高評価・コメント・長さ・投稿日（だれでも見られる数字） |
| 鍵2 `YT_CLIENT_ID` `YT_CLIENT_SECRET` `YT_REFRESH_TOKEN` | おすすめ | 平均視聴率・視聴時間・登録者が増えた動画・流入元・視聴者の年齢 |
| 鍵3 `ANTHROPIC_API_KEY` | 任意（Instagram用に登録済みならそのまま使われます） | 数字を読んで「方向性の文章・動画案・実験」を書く。無いとルールで判定 |

### 鍵1：YouTube Data API キー

1. Google Cloud Console（`console.cloud.google.com`）を開いて、チャンネルのGoogleアカウントでログイン
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前は `yt-growth` など → 作成
3. 左メニュー「APIとサービス」→「ライブラリ」→ `YouTube Data API v3` を検索 →「有効にする」
4. 同じく `YouTube Analytics API` も検索 →「有効にする」（鍵2で使う）
5. 「APIとサービス」→「認証情報」→「＋認証情報を作成」→「APIキー」
6. 出てきたキーをコピー（これが `YT_API_KEY`）

### 鍵2：アナリティクス用（Studioの数字を読むため）

1. 「APIとサービス」→「OAuth同意画面」→ ユーザーの種類「外部」→ アプリ名 `yt-growth`、メールは自分のものを入力 → 保存
2. 「テストユーザー」にチャンネルのGoogleアカウントを追加
3. **重要**：同意画面の「公開ステータス」を **「本番環境に公開」** にする
   （「テスト」のままだと鍵が**7日で切れて**止まります。自分だけで使うので審査は不要です）
4. 「認証情報」→「＋認証情報を作成」→「OAuthクライアントID」→ 種類「**デスクトップアプリ**」→ 作成
5. 表示された **クライアントID**（= `YT_CLIENT_ID`）と **クライアントシークレット**（= `YT_CLIENT_SECRET`）をメモ
6. 自分のパソコンでこのフォルダを開き、次をコピペして実行：

```bash
python3 get_refresh_token.py ここにクライアントID ここにクライアントシークレット
```

7. ブラウザが開くのでチャンネルのアカウントでログイン →「許可」
   （「このアプリは確認されていません」と出たら「詳細」→「移動」でOK。自分で作ったアプリです）
8. ターミナルに出た `YT_REFRESH_TOKEN=...` の `...` 部分をコピー

### 鍵を GitHub に登録する

1. GitHub でこのリポジトリを開く →「Settings」→「Secrets and variables」→「Actions」
2. 「New repository secret」で、次を1つずつ登録：

```
YT_API_KEY
YT_CLIENT_ID
YT_CLIENT_SECRET
YT_REFRESH_TOKEN
```

3. （任意）同じ画面の「Variables」タブで目標を変えられます：
   - `YT_GOAL` … 例：`中学生GKに向けた練習動画で、半年で登録者1万人`
   - `YT_CHANNEL_ID` … 別のチャンネルを分析したいときだけ

## ▶ 動かし方

### A：GitHub で毎朝じどう（おすすめ）

1. このしくみを**いつも使っているブランチ（main）に入れる**（自動実行は main でしか動きません）
2. 「Actions」タブ →「YouTube 毎朝の成長チェック」→「Run workflow」で1回テスト
3. 以後は**毎朝6:30（日本時間）**に自動で動きます
4. 結果を見る：GitHub で `youtube-growth/output/today.html` を開く
   （スマホで見やすく見たいときは、Raw 表示のURLをブラウザで開く or ファイルをダウンロード）

### B：自分のパソコンで動かす

```bash
cd youtube-growth
cp keys.local.example keys.local   # keys.local に鍵を書く
pip install anthropic              # 鍵3を使うときだけ
python3 analyze.py
```

`output/today.html` をブラウザで開けば完成です。

## 📁 できるファイル

| ファイル | 中身 |
|---|---|
| `output/today.html` | 毎朝のレポート（スマホ向け） |
| `output/today.json` | 同じ内容のデータ版 |
| `history/direction-log.md` | 方針の日記（新しい日が上）。チェックボックスで「やった」を管理できます |
| `history/directions.json` | 方針の記録（次の日のふり返りに使う） |
| `history/snapshots/日付.json` | その日の全動画の数字（昨日との差を出すために使う） |

---

## 💡 上手な使い方

1. **最初の1週間は記録をためる期間**。7日たつと「7日前との比較」、30日で「30日比較」が出ます。
2. 「今日やること」は**全部やらなくてOK。1つだけでも毎日**。
3. **実験は1週間に1つ**。同時にいろいろ変えると、何が効いたか分からなくなります。
4. 日記の `- [ ]` を `- [x]` にしておくと、自分のふり返りにも使えます。

## ❓ こまったとき

| 症状 | 直し方 |
|---|---|
| `HTTP 403 ... quota` | 1日の使用量オーバー。翌日には自動で戻ります（ふつうは1日1回なら余裕） |
| `HTTP 400 ... invalid_grant` | 鍵2が切れています。OAuth同意画面を「本番環境」にしてから、鍵2の6〜8をやり直す |
| アナリティクスが「未接続」 | 鍵2の3つがSecretsに入っているか確認 |
| クリック率（インプレッションCTR）が無い | YouTube の仕様で、APIでは取得できません。Studio で確認してください |
| 毎朝動かない | ワークフローが main ブランチに入っているか確認。60日間リポジトリに動きが無いと GitHub が自動停止するので、その場合は Actions 画面で「Enable」 |
