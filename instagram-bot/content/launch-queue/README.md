# 新モデル・先行予約 告知キュー

ここに広告画像（jpg / png / webp）を入れておくと、**毎日1本ずつ**自動で
告知投稿されます（AIがセールス文を自動生成）。ファイル名の順（1, 2, 3…）で出ます。
キューが空の日は何も投稿しません。投稿済みは `posted.json` に記録され、二度と出ません。

- 価格・発売日・先行予約日時などは、**画像に書かれていればそのまま反映**します。
  画像に無い情報は捏造しません。特定の日付・価格を必ず入れたい場合は `context.json`
  に `{ "ファイル名": "先行予約 11/25 10:00・税込12800円" }` のように一行メモを足してください。
