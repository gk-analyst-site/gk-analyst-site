# 🛒 楽天ROOM 半自動 出品アシスタント

楽天ROOMで「売れそうな商品」を**自動でさがして、投稿文まで自動で作る**しくみです。
あなたは最後にスマホでコピペして「投稿」ボタンを押すだけ。

> **なぜ完全自動じゃないの？**
> 「投稿ボタンを自動で押す」のは楽天ROOMの規約で禁止されていて、
> バレるとアカウントが止まります。だから**さがす・作るは全自動、投稿だけ手動**に
> しています。これが一番安全で、しかもほとんど手間ゼロです。

---

## 🧩 中学生向け・しくみの説明

```
① 楽天の公式API ──売れてる商品のデータ──► ② このプログラム ──今日の投稿リスト──► ③ あなた
   (データ屋さん)                            (売れ筋あつめ→投稿文づくり)              (コピペして投稿)
```

- **① 楽天の公式API**：「今どの商品が売れてるか」を楽天が正式に教えてくれる窓口。
- **② このプログラム(`fetch_products.py`)**：売れ筋を集めて、あなたの報酬リンクを付けて、
  楽天ROOM用の投稿文を自動で書き、スマホで見やすいページ(`today.html`)を作る。
- **③ あなた**：`today.html`を開いて「投稿文をコピー」→ 楽天ROOMに貼って投稿。

---

## 🔑 準備：3つの「鍵」を用意する（無料・スマホでもOK）

「鍵」がなくてもデモモードで動きますが、本番では次の3つが必要です。

### 鍵1：楽天ROOMのアカウント
- 楽天ROOMアプリをスマホに入れて、楽天IDでログインするだけ。
- プロフィールを少し埋めておくと、見てもらいやすくなります。

### 鍵2：楽天アフィリエイトID（＝報酬が入る仕組み）
1. 「楽天アフィリエイト」で検索してサイトを開く（楽天IDでそのまま使えます）。
2. ログインすると、あなた専用の**アフィリエイトID**がもらえます。
   （`xxxxxxxx.xxxxxxxx.xxxxxxxx.xxxxxxxx` のような文字列）
3. このIDをリンクに付けると、そのリンク経由で買われたとき報酬が入ります。

### 鍵3：APIアプリID（applicationId）＝売れ筋データを取る鍵
1. 「Rakuten Developers（楽天ウェブサービス）」で検索してサイトを開く。
2. 楽天IDでログイン →「アプリID発行」からアプリを新規登録。
   - アプリ名：なんでもOK（例：`room-helper`）
   - サイトURL：持っていなければ `http://localhost` でOK。
3. 発行された **applicationId**（数字の長い列）をメモ。

## 💻 使い方A：自分のパソコンで動かす

Python が入っていれば、追加インストールは不要です（標準機能だけで動きます）。

```bash
# 1) 鍵をセット（あなたの値に置き換えてください）
export RAKUTEN_APP_ID="ここにapplicationId"
export RAKUTEN_AFFILIATE_ID="ここにアフィリエイトID"

# 2) 実行
python3 rakuten-room/fetch_products.py

# 3) できたページを開く
#    rakuten-room/output/today.html をブラウザ or スマホで開く
```

鍵をセットせずに実行すると、**デモモード**でサンプル商品が表示されます（動作確認用）。

## ⚙️ 使い方B：毎朝じどうで動かす（GitHub Actions）

パソコンを開いていなくても、**毎朝6時に自動で売れ筋リストを作り直す**ことができます。
（`.github/workflows/rakuten-room-daily.yml` がその設定です）

### 鍵をGitHubに登録する
1. GitHubのこのリポジトリで **Settings → Secrets and variables → Actions** を開く。
2. **New repository secret** を押して、次の2つを登録：
   - 名前 `RAKUTEN_APP_ID` … 値はあなたのapplicationId
   - 名前 `RAKUTEN_AFFILIATE_ID` … 値はあなたのアフィリエイトID
3. これで毎朝、最新の`today.html`が自動更新されます。
   すぐ試したいときは **Actions タブ → このワークフロー → Run workflow** で手動実行できます。

## 🎯 出品する商品のえらび方（カスタマイズ）

`fetch_products.py` の上のほうにある設定を変えるだけです。

- `GENRES` … 集めたいジャンルの一覧。`(ジャンルID, "表示名")` を足したり消したり。
- `ITEMS_PER_GENRE` … 各ジャンルから何件拾うか。

### ジャンルIDの調べ方
楽天市場でジャンルのページを開くと、URLに `/category/xxxxx/` のような番号が出ます。
それがジャンルIDです。`genreId=0` は「総合ランキング」で、いつでも使えます。

## ❓ よくある質問

- **Q. 本当に稼げる？**
  A. 楽天ROOMの報酬は「見てくれる人・買ってくれる人」がいて初めて発生します。
     このツールは"投稿の手間ゼロ化"が目的。フォロワーを増やす・毎日続けることが大事です。

- **Q. 完全自動（投稿まで）にしたい**
  A. 技術的には可能ですが、楽天ROOMの規約違反でアカウント停止リスクがあります。
     このツールは安全重視で「投稿だけ手動」にしています。

- **Q. お金はかかる？**
  A. 楽天のAPIもアフィリエイトもGitHub Actionsも、この使い方なら無料の範囲です。
