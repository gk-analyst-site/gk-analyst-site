# etsy-seo — TheJapaneseArtPrints 売上改善ツール

Etsyショップ **TheJapaneseArtPrints**（shop_id `64586915`／商品: デジタルDL + POD）の
売上改善のための成果物一式。アップロードされたブログ自動化キット
(`blog-automation`) から、**APIキー不要で今すぐ使える部分**を抜き出し・再構築したもの。

## 背景（なぜ売れていなかったか）

出品51点に対し直近30日の表示がほぼ0 ＝「買われない」以前に **Etsy検索に出ていない**。
付属の監査で判明した主因:

- タグの共食い: `mount fuji print` が33商品、同一13タグセットが20商品以上。
  Etsyは同一キーワードで自店商品を1つしか表示しないため大半が非表示扱い。
- タグと画像の不一致: 桜・鳥居・畳・寺の商品まで「mount fuji」タグ。
- 8商品はタグ空 or 極端に短いタイトルで検索に一切出ない。

## 中身

| ファイル | 内容 |
|---|---|
| `generate_seo_rewrites.py` | 全51点のタイトル＋タグ13個を生成・検証するスクリプト（標準ライブラリのみ） |
| `etsy_rewrites_master.md` | Etsyへ**コピペ**する用の完成版（listing_id別） |
| `etsy_rewrites_master.csv` | スプレッドシート／一括管理用 |
| `mt-fuji-wall-art.md` | 送客用ブログ記事（約1,980語・キーワード `mt fuji wall art`） |
| `mt-fuji-wall-art_pins.md` | 上記記事用 Pinterest ピン5枚分の文言 |

## 生成・再生成のしかた

```bash
cd etsy-seo
python3 generate_seo_rewrites.py
```

- 制約（タグ各20字以内 / 1商品13タグ / 重複セットなし / タイトル140字以内）を
  自動検証し、違反があれば標準出力に表示する。
- 商品を追加・削除したら、スクリプト内の `L` テーブル（listing_id → 主題・角度・
  タイトル）を編集して再実行するだけ。
